# TaskPilot - AI-Powered Project Management

TaskPilot is a responsive SaaS landing page for an AI-powered project management platform designed to help remote teams organise tasks, monitor progress, and manage projects more effectively.

The landing page presents how AI can support smarter task management, project visibility, and team collaboration.

## Features

- Modern landing page: Clean, responsive design with a purple and neon mint visual identity.
- Dark and light themes: Switch between themes with saved user preferences.
- Responsive navigation: Mobile-friendly navigation menu.
- Active navigation:Highlights the section currently being viewed.
- Feature showcase:Presents TaskPilot's AI-powered project management capabilities.
- Pricing plans:Displays Starter, Pro, and Enterprise options.
- Interactive demo sign-up:Demonstrates a basic sign-up interaction.
- Hover effects:Adds interactive feedback to feature, pricing, and testimonial cards.
- Accessibility:Keyboard navigation, visible focus states, and improved colour contrast.

## Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension for VS Code (recommended).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mercykimutaicom-spec/taskpilot-landing-page.git
   ```

2. Navigate into the project directory:

   ```bash
   cd taskpilot-landing-page
   ```

3. Open the project in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` using Live Server, or open it directly in your browser.
